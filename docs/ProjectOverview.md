# Project Overview

## 1. System Objectives

- What problem are you solving?
  - Manual grass cutting is difficult, time-consuming, and costly because it requires labor and gasoline.
  - The farm owner lacks a reliable way to monitor battery, solar energy, and mower connection status.
  - There is an opportunity to generate extra income by renting out the mower when not in use.

- Who benefits and how?
  - Farm owner: saves time, labor, and fuel cost.
  - Farmers and employees: easier mowing operation and monitoring.
  - Renters: can book the mower for their own farm use.

## 2. Proposed Scope

- Modules/systems to integrate:
  - Auth / PIN lock
  - Web and mobile control
  - Solar and battery monitoring
  - GPS navigation and obstacle detection

- In-scope features for Performance Task 3:
  - Project kickoff and requirements gathering
  - Repository setup and documentation
  - Context diagram
  - Initial project overview

- Out-of-scope for now:
  - Full weather protection
  - Smart self-learning navigation
  - Large-area operation

## 3. Stakeholders

- KMJC Integrated Farm Owner — needs safe, efficient, and low-cost mowing.
- Farmers — want easier grass cutting and rental access.
- Employees — will operate and monitor the mower.

## 4. Tools & Technologies

- Languages/Frameworks: React, Firebase, JavaScript
- Integration approach: REST APIs, Webhooks, IoT messaging
- Repos/Services: GitHub, GitHub Actions
- Testing tools: Jest, Postman, manual testing
